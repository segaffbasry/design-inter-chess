# Chess.com Play concept

An interactive desktop prototype for a calmer, more atmospheric Chess.com pre-game experience.

## Product thesis

Chess.com currently treats the board as a preview beside controls. This concept turns the board itself into the invitation to play. Before matchmaking, perspective and restrained fog create anticipation. On Play, the atmosphere clears and the board resolves into a readable game state.

## Prototype

- Default: Rapid · 10 min, optimized for a returning player
- Change mode: Rapid, Blitz, or Daily
- Play: transitions from atmospheric staging to a clear board

Run locally with `npm run dev`.
